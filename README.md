# Shrinking Cities Ecological Trajectories

This repository provides the analysis code accompanying our study of ecological trajectories and their driving mechanisms in shrinking cities in China.

## Contents

- `psem.zip`: R code for the baseline piecewise structural equation model and temporal–spatial robustness analyses, including AR(1) correction, residual Moran’s I tests, and Moran’s eigenvector map (MEM) filtering.
- `bayesian-spatiotemporal-changepoints.zip`: Python code for the Bayesian hierarchical spatiotemporal changepoint model with an explicit no-change state.

## Requirements

- R and the packages specified in `install_packages.R`
- Python 3.10 or later and the dependencies specified in `pyproject.toml`

Detailed installation and execution instructions are provided in the README file within each package.

## Data Availability

This repository contains source code only. Study data, geographic coordinates, model outputs, figures, and manuscript files are not included. Data access is described in the Data Availability Statement of the associated article.
